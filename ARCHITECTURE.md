# Architecture

`index.html` is generated by `build.py` from `src/`. All JS files are concatenated, in the order of
`JS_FILES` in `build.py`, inside ONE IIFE (`'use strict'`), so every top-level `var`/`function` is shared
across files. No modules, no bundler. Order matters for top-level statements (var initialisers,
`addEventListener` calls); function declarations are hoisted. `python3 build.py --local` writes
`dist/local.html` without Firebase (local mode, no login gate). `node tests/run.js` runs all tests.

## src files (in build order)
- `head.html` doctype, meta, title, fonts (build.py inserts `<meta name="build">` after the charset meta). `styles.css` all CSS, themes via `[data-theme]` on `<html>`. `body.html` markup (ids: `status`, `viewSw`, `who`, `plist`, `form`, `kpis`, `tabs`, `view`, `appSim`, `appIdeas`, `modal`, `toast`, `gate`, `lightbox`, `menu`). `firebase-config.html` the 3 Firebase compat 10.12.2 script tags + `window.FIREBASE_CONFIG` (omitted by `--local`).
- `core.js` pure calculations: `n(v)` (parse, negatives to 0), `IVA`, `calcSim(sim, alloc?)` -> landed cost `r` (goods, freight, cif, duty, iva, total, net, perUnitNet...), `lclAlloc(products, cfg)` shared sea freight split, `FULL`/`fullCost()` Mercado Libre Full, `isMercadoLibre(mk)`, `calcPL(r, pl, mk, fx)` -> per-unit P&L in CLP (profit, margin, beRoas, tRrp, ivaPay...). No DOM; tests load it in Node.
- `util.js` `$(id)`, `ask(text, okLabel, fn)` confirm modal, `closeModal()`, `toast(text)`, `esc()` HTML escape, formatters `grp usd clp pct m3`, `uid()`, `COLORS`.
- `state.js` `DEFAULT_SIM`, `DEFAULT_PL`, `defaultMk()` marketplaces, `blankProduct()`, `seedProduct()` (id `p_seed`), `baseline()`, `syncDuty()`, normalisers `normProduct normSettings normIdea normState`, `mode`, `load()`, `save()`, `saveUI()`, `saveLocalData()`, `setStatus(st)`, `S = load()`, `cur()`, `mkById()`, `lclCfg()`, `LCL`, `CACHE`, `recompute()`, what-if helpers `scen() unitCbm() fillQty()`.
- `form.js` `SPEC`, `ADV`, `fieldHtml()`, `buildForm()`, `formBuilt`, `getVal/setVal(k)`, `fillForm()`, `applyVis()` (visibility, hints, last edit, links, photos), `renderList()` product list.
- `views.js` `TABS`, `renderKpis()`, `renderTabs()`. `view-overview.js` `vOverview`, `view-cost.js` `dutyCard`+`vCost`, `view-pl.js` `vPL`, `view-channels.js` `vChannels`, `view-ship.js` `vShip`.
- `render.js` `renderView()`, `refresh(skipForm)`, `changed(skipForm)`.
- `events.js` form/list/tab/view listeners, `addProduct()`, duplicate/delete/reset/export/import buttons.
- `ui.js` menu, modal buttons, Escape key, `theme(t)` (stored in `importsim.v2.theme2`).
- `ideas.js` `STAT`, `ideaFilter`, `safeUrl fdate fdateTime`, saturation, `renderIdeas()`, `showView()` (Simulator/Ideas switch), idea events.
- `photos.js` resize to JPEG data URLs (`p.photos[] = {data}`), `renderPhotos()`, lightbox.
- `sync.js` Firebase shared mode: `FB`, `PROFILES`, `ALLOWED` (emails -> profile id), `fbUser fbDb profile who`, `canon()`, `dirty()`, `scheduleSync()` (600 ms debounce), `syncUp()`, `onItems()`, `onIdeas()`, `renderWho()`, `flushSync()`, `openProfile(pid)`, `leaveShared()`, `gate(state, msg)`, `initFirebase()`.
- `main.js` startup: `refresh(false); setStatus('local'); initFirebase();`.

## Key shared state and calls
- `S` = `{ products[], active, tab, view: 'sim'|'ideas', sumView, me, ideas[], settings }`. `cur()` = active product.
- After changing `S`: call `changed(skipForm)` (= `save()` + `refresh()`). `skipForm=true` while the user types in the form. `refresh()` = `recompute()` + list, KPIs, tabs, view, form, `showView()`. Set `formBuilt = false` first if the marketplace list or SPEC-driven markup must be rebuilt.
- `CACHE[productId] = { r: calcSim result, pl: calcPL result, mk }`, filled by `recompute()`; `LCL` is the shared-shipment allocation.
- `save()`: UI choices to localStorage; data to localStorage (`mode === 'local'`) or `scheduleSync()` (`mode === 'shared'`).
- `mode` 'local'|'shared'. `who` = display name of the signed-in user ('André'/'Agustín'); `profile` = profile being edited ('andre'/'agustin'), may differ from the user.
- `ask()` for confirmations, `toast()` for short messages, `setStatus('saved'|'saving'|'local'|'unsaved'|'wait'|'toobig')` for the badge.

## Adding a tab (view)
1. Add `['id', 'Label']` to `TABS` (views.js).
2. Create `src/view-id.js` with `function vId(p, c) { return '<div class="card">...</div>'; }` (p = product, c = `CACHE[p.id]`; return HTML, escape text with `esc()`).
3. Register it in the map in `renderView()` (render.js) and add the file to `JS_FILES` in build.py (before `render.js` by convention).
4. Clicks/changes inside `#view` go through the delegated listeners in events.js (`data-split`, `data-sum`, `data-open`, `data-add`, `data-ship`); add new `data-*` handlers there.

## Adding a form field
1. Add `['prefix.key', 'Label', showCondition?, options?]` to a group's `f` in `SPEC` (form.js). Prefixes: `s.` = `p.sim`, `p.` = `p.pl`, `n.` = product top level, `m.` = current marketplace, `g.` = `S.settings`, `l.` = `S.settings.lcl`. `options` = array -> `<select>`.
2. Give it a default in `DEFAULT_SIM`/`DEFAULT_PL` (state.js; `normProduct` merges defaults, so old saved products get it). Values are strings.
3. Optional: add to `ADV` ("More options"), or a `data-show` condition in `applyVis()`.
4. Use it in `calcSim`/`calcPL` (core.js) via `n(s.key)`, then update the golden values in tests/run.js only if the change is intended.

## Storage
- localStorage: `importsim.v2.local` (products, settings, ideas, me), `importsim.v2.ui` (active, tab, view, sumView), `importsim.v2.theme2`, `importsim.profile` (last profile).
- Firestore `workspaces/andre-agustin/profiles/{andre|agustin}/items/{productId}`: product `{ id, name, created, notes, links: [{url}], photos: [{data}], sim: {...DEFAULT_SIM}, pl: {...DEFAULT_PL}, updatedBy, updatedAt }` (ids start `p_`; doc must stay under ~900 KB).
- Same collection, doc `settings`: `{ fx, lcl: { rate, min, agent, split: 'space'|'value' }, sat: { low, high }, mk: [{ id, name, commission, fixed, fixedMax?, ship, shipMin?, verified, official, note }] }`.
- Firestore `workspaces/andre-agustin/ideas/{ideaId}` (ids start `i_`, shared by both profiles): `{ id, name, link, notes, author, created, updated, editedBy, status: idea|investigating|test|discarded, exists: unknown|yes|no, price, listings }`.
- Only docs that differ from the last synced copy (`canon()`) are written. Access: `firestore.rules` + `ALLOWED` in sync.js.
